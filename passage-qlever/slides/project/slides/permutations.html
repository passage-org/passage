Six sorted permutations

Every triple is stored six times, each time sorted by a different key order. The first column is called col0, and its distinct values are the relations.

permutation answers relations (distinct col0) blocks
PSO · POS bound predicate 86 366
SPO · SOP bound subject 521,585 234
OPS · OSP bound object 1,005,832 249

A scan picks the permutation whose key order puts the bound components first. The matching triples are then a contiguous range — which is what makes an offset meaningful at all.

This much is published: Bast et al., Knowledge Graphs, 2023, §1.5.2. Everything from here on is not.
